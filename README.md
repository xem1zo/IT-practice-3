# Практическая работа №3: Представления (VIEW) в MySQL

## 🎯 Цель работы
Изучить механизм представлений (VIEW) в MySQL, научиться создавать простые и сложные VIEW, работать с обновляемыми представлениями, использовать `WITH CHECK OPTION`, а также настроить логирование в файл и сделать дамп БД.

## ⚙️ Выполненные шаги
1. Создана база данных `sql_practice` и таблицы `customers`, `orders`.
2. Создано простое VIEW `moscow_customers` (фильтрация по городу).
3. Создано VIEW `customer_summary` с JOIN и агрегацией (сводка по клиентам).
4. Создано обновляемое VIEW `active_customers`.
5. Создано VIEW с `WITH CHECK OPTION` для защиты от вставки неверных данных.
6. Создан дамп базы данных `dump_clean.sql`.
7. Выгружен и отфильтрован лог `my_actions.log`.
